 # Bonus Knowledge

Q How to margin Auto

margin:auto;

Centers block elements horizontally.

Example

.card{

width:400px;

margin:auto;

}

# Universal Reset 

Professional developers add this to almost every project:

*{

margin:0;

padding:0;

box-sizing:border-box;

}

This removes default browser spacing and ensures consistent sizing.
