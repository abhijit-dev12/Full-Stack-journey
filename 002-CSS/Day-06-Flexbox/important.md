# CSS Notes - Day 6

## Flexbox

Flexbox is a one-dimensional layout system.

It arranges items in rows or columns.

---

## display:flex

Turns an element into a flex container.

```css
display:flex;
```

---

## flex-direction

Controls the direction.

```css
flex-direction:row;

flex-direction:column;
```

---

## justify-content

Controls horizontal alignment.

Values

- flex-start
- center
- flex-end
- space-between
- space-around
- space-evenly

---

## align-items

Controls vertical alignment.

```css
align-items:center;
```

---

## gap

Adds spacing.

```css
gap:20px;
```

---

## flex-wrap

Allows items to move to the next line.

```css
flex-wrap:wrap;
```
