# CSS Notes - Day 1

## What is CSS?

CSS stands for Cascading Style Sheets.

CSS is used to style HTML webpages.

HTML creates the structure.

CSS makes the webpage beautiful.

---

## Why CSS?

Without CSS

- Plain webpage
- No colors
- No layout
- No responsiveness

With CSS

- Colors
- Fonts
- Animations
- Responsive Design
- Modern UI

---

## CSS Syntax

selector {

    property: value;

}

Example

p{

color:red;

}

---

## Inline CSS

Applied inside HTML tags.

Example

<h1 style="color:red;">

Advantages

✔ Quick

Disadvantages

❌ Hard to maintain

---

## Internal CSS

Written inside

<style>

tag.

Advantages

✔ Good for single pages

Disadvantages

❌ Not reusable

---

## External CSS ⭐

Written in a separate file.

style.css

Advantages

✔ Professional
✔ Reusable
✔ Easy to maintain
✔ Faster websites

Used in almost every real project.
