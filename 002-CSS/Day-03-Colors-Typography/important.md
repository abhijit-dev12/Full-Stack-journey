Interview Questions
1. How many ways can you define colors in CSS?

✅ Named Color

✅ HEX

✅ RGB

✅ RGBA

2. Difference between RGB and RGBA?

RGB has no transparency.

RGBA includes an Alpha value (opacity).

3. What does font-weight do?

Controls the thickness of text.

4. Difference between text-align and text-decoration?
text-align controls alignment.
text-decoration adds or removes decorations like underline.
5. What is the difference between em and rem?
em is relative to the parent element.
rem is relative to the root (html) element.
