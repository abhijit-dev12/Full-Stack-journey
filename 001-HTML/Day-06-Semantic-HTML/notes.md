# HTML Notes - Day 6

## What is Semantic HTML?

Semantic HTML uses meaningful tags that describe the purpose of the content.

Example:

<header>
<nav>
<main>
<footer>

Instead of:

<div>

---

## Header

Contains the website logo, title, or top content.

```html
<header></header>
```

---

## Navigation

Contains links to different pages.

```html
<nav></nav>
```

---

## Main

Contains the main content of the webpage.

```html
<main></main>
```

---

## Section

Groups related content together.

```html
<section></section>
```

---

## Article

Represents an independent piece of content.

Examples:
- Blog post
- News article
- Product review

```html
<article></article>
```

---

## Aside

Contains related information.

Examples:
- Sidebar
- Ads
- Recent posts

```html
<aside></aside>
```

---

## Footer

Contains copyright, contact information, or links.

```html
<footer></footer>
```

---

## div vs Semantic Tags

div

- Generic container
- No meaning

Semantic Tags

- Describe the content
- Better SEO
- Better Accessibility
- Easier to read
